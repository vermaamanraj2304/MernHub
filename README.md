# MERN Learning Hub — Full-Stack Engineering Platform

Zero to Job-Ready MERN Architecture Learning Hub featuring bilingual (English & Hinglish) interactive lessons, real-world Indian analogies, runnable code snippets, and 14,000+ MCQs across 16 Master Modules.

---

## 📁 Repository Structure

```
├── frontend/                     # Complete React 18 + Vite Web Application
│   ├── src/
│   │   ├── components/           # UI Components, QuizRenderer, Sidebar, Navbar
│   │   ├── context/              # LanguageContext, ThemeContext, ProgressContext
│   │   ├── data/                 # curriculum.js, masterChecklist.js, contentLoader.js
│   │   │   └── content/          # 120+ in-depth subtopic lessons (21+ MCQs each)
│   │   ├── pages/                # Home, TopicPage, ChecklistPage, NotFound
│   │   └── utils/                # iconMap.jsx
│   ├── public/                   # Static assets & favicon
│   ├── package.json              # Frontend dependencies
│   ├── vite.config.js            # Vite build & chunking config
│   └── tailwind.config.js        # Custom theme & typography styling
│
├── package.json                  # Root proxy scripts
└── README.md
```

---

## 🚀 Quick Start

From the root directory:

```bash
# Run local development server (starts on http://localhost:3000)
npm run dev

# Build for production
npm run build

# Preview production bundle
npm run preview
```

Or navigate directly to the `frontend/` folder:

```bash
cd frontend
npm run dev
```
